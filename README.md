# 麻糬跳跳（Mochi Jump）

原創的橫向捲軸闖關小遊戲，單一 HTML 檔，不需安裝，用瀏覽器打開 `index.html` 就能玩。

## 內容
- 6 個關卡：晨光草原、黃昏山丘、星夜溪谷、雲端花園、地底礦坑、熔岩城堡
- 道具：包子（護體，可頂碎磚塊）、星星糖（無敵 8 秒）、翅膀（空中二段跳）、綠茶（+1 命）、沙漏（+60 秒）
- 機關：彈簧、移動木板、雲朵平台、尖刺、熔岩、中途點
- 敵人：刺栗子、蜜蜂、刺蝟（不能踩）
- 破關後會解鎖關卡，可在標題畫面選關；最高分存在瀏覽器 localStorage

## 操作
| 動作 | 鍵盤 | 手機 |
|---|---|---|
| 移動 | ← → / A D | ◀ ▶ |
| 跳（按久跳更高） | 空白 / ↑ / Z | 跳 |
| 衝刺 | Shift / X | 衝 |
| 暫停 / 靜音 | P / M | 畫面上方按鈕 |

## 執行
直接用瀏覽器開啟 `index.html`。字型從 Google Fonts 載入，離線時會改用系統字型。

## 測試狀態
已在 Chromium 無頭瀏覽器中進入各關短暫遊玩，沒有出現頁面錯誤；尚未完整驗證每一關都能從頭玩到尾，也尚未在實體手機上測試觸控。
